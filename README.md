# 好命密碼 · 數字磁場分析工具

跟愛德華（Edward）《好命密碼》門派邏輯，並結合上傳教材實務規則。

## 規則

- **0**：隱性／弱化橋樑（所有號碼類型都計）
- **5**：只喺**電話號碼**先計；其他類型跳過
- 字母 A=01 … Z=26
- 先天（出生）／流年（身份證）／後天分身（電話）角色分開

## 解讀風格

口語故事為主，括號標明係邊粒星造成呢段感覺。

## 使用

直接打開 `index.html`，或 deploy 去 Netlify：

1. 連呢個 repo
2. Publish directory 留空或設 `/`
3. Deploy
